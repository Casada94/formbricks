## Elements

![Overview of Address question type](/images/surveys/question-type/address/editor.webp)

### Question

Provide a question to describe the address information you are requesting.

### Description

Optionally, add a description to guide the user.

### Toggle Fields

You can choose to show and require any or all of the following fields in the form:

- Address Line 1
- Address Line 2
- City
- State
- Zip Code
- Country

Each shown field can be Optional, Required, or One of. Mark two or more fields as One of when any one of them is enough: the respondent must fill in at least one, and may fill in more than one. A single field marked One of is required on its own. Fields with the same group number share that requirement, and a different number is a separate requirement.
